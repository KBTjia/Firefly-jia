# 一、五大主流浏览器及其内核

> 浏览器内核通常分为两部分：
> - **渲染引擎**：负责解析 HTML / CSS，将页面绘制到屏幕上；
> - **JS 引擎**：负责解析和执行 JavaScript 代码。

| 浏览器  | 渲染内核        | JS 引擎       |
| ------- | --------------- | ------------- |
| IE      | Trident         | JScript       |
| Chrome  | WebKit → Blink  | V8            |
| Safari  | WebKit          | JavaScriptCore |
| Firefox | Gecko           | SpiderMonkey  |
| Opera   | Presto → Blink  | Carakan → V8  |

> 补充说明：
> - Chrome 最初使用 WebKit，2013 年起从 WebKit 分支（fork）出 **Blink**；
> - Opera 早期使用自家的 **Presto** 内核，后来也随 Chrome 改用了 Blink。

# 二、浏览器的历史与 JavaScript 的诞生

1. **1990 年**：蒂姆·伯纳斯·李（Tim Berners-Lee）在欧洲核子研究中心（CERN）发明了万维网（World Wide Web），并开发了第一个网页浏览器 **WorldWideWeb**（后改名 **Nexus**），它基于 **libwww** 库，允许人们浏览他人编写的网站。

2. **1993 年**：美国伊利诺伊大学的 **NCSA** 组织（核心成员 **马克·安德森** Marc Andreessen）开发了 **Mosaic** 浏览器，它可以显示图片，是真正意义上的「图形化」浏览器，让普通人也能够上网。

3. **1994 年**：马克·安德森与吉姆·克拉克（Jim Clark，SGI 硅图公司创始人）共同创立了 **Mosaic Communications Corporation**，后改名为 **Netscape Communications Corporation**（网景公司）。

4. **1994 ~ 1995 年**：网景公司开发了 **Netscape Navigator** 浏览器，1995 年发布正式版本后迅速成为最受欢迎的浏览器之一，市场占有率一度超过 90%。

5. **1995 年**：网景公司的 **布兰登·艾奇（Brendan Eich）** 只用了 10 天时间，在 Netscape Navigator 中开发出一种脚本语言，最初命名为 **LiveScript**。

6. **1995 年**：微软从 **Spyglass** 公司获得了 Mosaic 浏览器的授权，开始开发 **Internet Explorer（IE）**，并在 Windows 操作系统中捆绑发布，IE 逐渐占领市场。

7. **1996 年**：当时 Java 大火，网景公司为了「蹭热度」，把 LiveScript 改名为 **JavaScript**。这也造成了很多人误以为 JavaScript 和 Java 是同一种语言。实际上它们是两种完全不同的编程语言，设计目标、语法和用途都不同。

8. **1996 年**：微软发布 IE 3.0，内置了自己的脚本语言 **JScript**，与 Netscape 展开激烈的「浏览器大战」。

9. **2001 年**：IE 6 与 Windows XP 一起诞生。此时浏览器内核已经明确分为「渲染引擎」和「JS 引擎」两部分，IE 6 的 JS 引擎就是 JScript，性能较差，也带来了很多性能问题与安全漏洞。

10. **2003 年**：Mozilla 公司发布 **Firefox** 浏览器，它是在 Netscape Navigator 基础上改进而来的，采用了全新的渲染引擎 **Gecko** 和 JS 引擎 **SpiderMonkey**，性能大幅提升，成为 IE 的有力竞争对手。

11. **2008 年**：Google 基于 WebKit、Blink、Gears 等技术开发了 **Chrome** 浏览器，并推出 **V8** 引擎。V8 的两大特点：
    - 直接把 JS 编译成机器码执行（速度快）；
    - 可以独立于浏览器运行（这也为后来的 Node.js 奠定了基础）。

12. **2009 年**：甲骨文（Oracle）收购了 Sun 公司，获得 Java 的授权，继续开发 Java 语言。

13. **2015 年**：ECMA 国际组织发布 **ECMAScript 6（ES6 / ES2015）** 标准，带来了大量新的语言特性和改进，成为现代 JavaScript 的基础。

14. **2015 年**：微软发布 **Edge** 浏览器，采用全新的渲染引擎 **EdgeHTML** 和 JS 引擎 **Chakra**。

15. **2020 年**：微软宣布将 Edge 转向基于 **Chromium** 的内核，采用 Blink 渲染引擎和 V8 JS 引擎，进一步提升了性能和兼容性。

16. **2021 年**：Google 发布 Chrome 90、Mozilla 发布 Firefox 100、Apple 发布 Safari 15，各家持续优化各自的引擎，提升性能与安全性。

> 核心结论：JavaScript 诞生于 1995 年的 Netscape，由 Brendan Eich 创建；最初叫 LiveScript，后来改名 JavaScript（与 Java 无关，只是营销上的借势）。

# 三、ECMA 与 ECMAScript

- **ECMA**（European Computer Manufacturers Association）：欧洲计算机制造商协会，负责评估、开发和认可电信、计算机方面的标准。
- **ECMA-262**：脚本语言的规范，也就是 **ECMAScript** 的标准文档。
- **ES5 / ES6**：ECMAScript 的版本代号（ES6 即 ES2015）。

> 关键理解：**ECMAScript 只是「标准 / 规范」，不是一门具体的语言。** JavaScript 是这套规范最主流的实现（其他实现还有 JScript、ActionScript 等）。

# 四、编程语言

## 1. 编译型语言与解释型语言

按「翻译过程」的不同，编程语言可分为两类：

| 类型   | 翻译过程                                        | 特点                               |
| ------ | ----------------------------------------------- | ---------------------------------- |
| 编译型 | 源码 → 编译器编译 → 机器码（可执行文件）→ CPU 执行 | 一次编译，多次运行，执行速度快     |
| 解释型 | 源码 → 解释器逐行解释执行 → CPU 执行              | 无需单独编译，开发调试灵活，跨平台性好 |

- 编译型代表：C、C++、Go、Rust 等。
- 解释型代表：JavaScript、Python 等。

> JavaScript 是**解释型语言**，代码在运行时由浏览器的 JS 引擎逐行解释执行。这使得它开发周期短、跨平台兼容性好，但在纯计算性能上通常不如编译型语言。（现代 JS 引擎如 V8 会引入 JIT 即时编译来优化性能。）

## 2. 高级语言与低级语言

| 类型     | 特点                                                 | 举例              |
| -------- | ---------------------------------------------------- | ----------------- |
| 低级语言 | 贴近硬件，难读难写，执行效率高（机器语言、汇编语言） | 机器码、汇编      |
| 高级语言 | 贴近人类思维，易读易写，需翻译成机器码才能运行       | C、Java、JavaScript |

## 3. 编程语言的四个基本要素

任何编程语言，本质上都离不开以下四种能力：

1. **变量**：用来存储数据的「容器」；
2. **数据结构**：用来组织和管理数据的「结构」（如数组、对象）；
3. **函数**：封装一段可复用逻辑的「代码块」；
4. **运算能力**：对数据进行计算与逻辑判断的能力。

# 五、JavaScript 的三大组成

| 组成部分   | 全称                     | 负责内容                                                             | 规范制定方 |
| ---------- | ------------------------ | -------------------------------------------------------------------- | ---------- |
| ECMAScript | —                        | JS 语法核心：语法、变量、关键字、保留字、值、对象、继承、函数、引用类型 | ECMA       |
| DOM        | Document Object Model    | 文档对象模型：操作页面结构与内容                                     | W3C        |
| BOM        | Browser Object Model     | 浏览器对象模型：操作浏览器窗口等                                     | 无统一规范 |

- **ECMAScript**：规范化的脚本语言，是 JS 的语法核心。
- **DOM**：文档对象模型，由 W3C 制定规范，用于操作 HTML 文档（增删改查节点）。
- **BOM**：浏览器对象模型，没有统一规范，用于操作浏览器本身（如 `window`、`location`、`history`）。

# 六、单线程与多线程

## 1. 概念对比

| 概念   | 说明                                                           |
| ------ | -------------------------------------------------------------- |
| 单线程 | 同一时间只能执行一个任务，任务之间需要排队等待，可能出现阻塞     |
| 多线程 | 同一时间可以执行多个任务，任务之间并行处理，提高效率和响应速度 |

> JavaScript 是**单线程**的：同一时间只能执行一个任务，当一个任务执行时，其他任务需要等待，可能会出现阻塞现象。

## 2. 单线程如何「模拟」多线程

JavaScript 通过 **轮转时间片**（时间分片）的方式，在短时间内轮流执行多个任务的片段，从而「模拟」出多线程的效果：

1. 存在任务 1、任务 2（多个任务）；
2. 把任务 1、任务 2 切分成一个个小片段；
3. 随机排列这些任务片段，组成一个队列；
4. 按照队列顺序，把任务片段逐个送进 JS 进程；
5. JS 线程依次执行一个又一个任务片段。

> 补充：现代 JS 还通过 **事件循环（Event Loop）** 配合**异步任务**（定时器、回调、Promise 等）来避免长时间阻塞主线程。

# 七、变量

## 1. 什么是变量

变量是程序中用来**存储数据**的一个「有名字的容器」。我们可以把一个值保存到变量里，之后通过变量名读取、修改或使用这个值。

```js
// 声明变量并赋值
let name = "jia";   // 用变量 name 保存字符串 "jia"
let age = 18;       // 用变量 age 保存数字 18

console.log(name);  // 输出 jia
```

## 2. 声明变量的三种方式

| 关键字   | 说明                                       | 出现版本   |
| -------- | ------------------------------------------ | ---------- |
| `var`    | 早期声明方式，存在变量提升、作用域问题     | ES5 及更早 |
| `let`    | 块级作用域，可重新赋值，推荐使用           | ES6        |
| `const`  | 声明常量，声明后不能重新赋值               | ES6        |

```js
var a = 1;   // 老写法，作用域较混乱，尽量少用
let b = 2;   // 推荐：可变变量
const c = 3; // 推荐：常量（声明时必须赋值，之后不能改）
```

## 3. 变量的命名规则（标识符）

1. 只能由**字母、数字、下划线 `_`、美元符号 `$`** 组成；
2. **不能以数字开头**（`1name` 不合法）；
3. **区分大小写**（`name` 与 `Name` 是两个不同变量）；
4. **不能使用关键字和保留字**（如 `var`、`let`、`const`、`if`、`for`、`function` 等）；
5. 建议使用有意义的**驼峰命名法**（camelCase），例如 `userName`、`totalPrice`。

```js
let userName = "jia";   // 合法，驼峰命名
let _temp = 1;          // 合法，下划线开头
let $price = 100;       // 合法，$ 开头
// let 1num = 10;       // 非法：不能以数字开头
// let var = 1;         // 非法：var 是关键字
```

## 4. `var`、`let`、`const` 的区别

| 区别点         | `var`                        | `let`                        | `const`                    |
| -------------- | ---------------------------- | ---------------------------- | -------------------------- |
| 作用域         | 函数作用域                   | 块级作用域                   | 块级作用域                 |
| 重复声明       | 允许                         | 不允许（同作用域内）         | 不允许                     |
| 变量提升       | 会提升（值为 `undefined`）   | 存在暂时性死区，不会初始化   | 存在暂时性死区             |
| 是否必须初始化 | 否                           | 否                           | 是（声明时必须赋值）       |
| 能否重新赋值   | 能                           | 能                           | 不能                       |

# 八、JS 值（数据类型）

JS 中的「值」按存储方式分为两大类：**原始值**和**引用值**。

## 1. 原始值（Primitive Values，7 种基本类型）

| 类型        | 说明                                               | 示例                 |
| ----------- | -------------------------------------------------- | -------------------- |
| `string`    | 字符串                                             | `"hello"`、`'abc'`   |
| `number`    | 数字（整数和小数统一都是 number）                  | `1`、`3.14`          |
| `boolean`   | 布尔值，只有两个取值                               | `true` / `false`     |
| `null`      | 空值，表示「什么都没有」                           | `null`               |
| `undefined` | 未定义，变量已声明但未赋值                          | `undefined`          |
| `symbol`    | 唯一、不可变的值（ES6 引入）                        | `Symbol("id")`       |
| `bigint`    | 大整数，可表示超出 number 安全范围的整数（ES2020）  | `123n`               |

## 2. 引用值（Reference Values）

引用类型是**对象**，包括：`Object`、`Array`（数组）、`Function`（函数）、`Date`、`RegExp` 等。

```js
let obj = { name: "jia" };   // 对象
let arr = [1, 2, 3];          // 数组
let fn = function () {};      // 函数
```

## 3. 使用 `typeof` 判断类型

```js
typeof "hello";          // "string"
typeof 100;              // "number"
typeof true;             // "boolean"
typeof undefined;        // "undefined"
typeof null;             // "object"（历史遗留 bug，null 实际是原始值）
typeof Symbol();         // "symbol"
typeof 10n;              // "bigint"
typeof {};               // "object"
typeof [];               // "object"
typeof function () {};   // "function"
```

## 4. 原始值与引用值的区别

| 区别点     | 原始值                             | 引用值                                       |
| ---------- | ---------------------------------- | -------------------------------------------- |
| 存储内容   | 直接存储「值本身」                 | 存储「内存地址（引用）」                     |
| 赋值 / 传参 | 拷贝值（互不影响）               | 拷贝引用（指向同一对象，会互相影响）         |
| 可变性     | 不可变（修改会生成新值）           | 可变（可以增删改属性）                       |

```js
// 原始值：拷贝的是值，互不影响
let a = 1;
let b = a;
b = 2;
console.log(a); // 1（a 不变）

// 引用值：拷贝的是地址，指向同一对象
let obj1 = { x: 1 };
let obj2 = obj1;
obj2.x = 999;
console.log(obj1.x); // 999（obj1 也跟着变了）
```

# 总结

- JavaScript 诞生于 1995 年的 Netscape，由 Brendan Eich 创建，与 Java 无关；
- ECMAScript 是 JS 的语法标准（ECMA-262），本身不是语言；
- JavaScript 是解释型、单线程的高级语言，靠时间分片和事件循环模拟多线程；
- JS 由三部分组成：ECMAScript（语法核心）、DOM（文档操作）、BOM（浏览器操作）；
- 变量是存储数据的容器，使用 `let` / `const` 声明，遵循标识符命名规则；
- JS 的值分为原始值（string / number / boolean / null / undefined / symbol / bigint）和引用值（object）。
